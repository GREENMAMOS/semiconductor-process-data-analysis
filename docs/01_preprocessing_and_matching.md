# 1. 전처리와 Input–Output 연결

[전체 분석으로 돌아가기](../README.md)

## 목적과 데이터 구조

설비 센서는 시간별 공정 상태를, Recipe는 입력 조건을, wafer 계측값은 공정 결과를 나타냅니다. 각각의 비교 단위와 식별자를 확인한 뒤 계산했습니다.

| 자료 | 단위·식별자 | 확인 내용 |
|---|---|---|
| 프로젝트2 센서 | 시간, Run1–3 | Si2H6 유량(sccm), 초기 과도 구간 |
| 프로젝트3 공정 파라미터 | Run 번호 1–25 | Recipe, Gas, Pressure, Power, Temperature, Time |
| 프로젝트3 계측 데이터 | 조건 번호, WF, ITEM_ID, 위치 1–49 | THK1_1_TOP(Å), GOF_1 |
| 좌표 | 위치 번호 1–49 | x(mm), y(mm) |

## 공정 Input 정리

1. 공정 파라미터 표의 다단 헤더에서 변수명과 단위를 확인했습니다.
2. 공정 실행 순서인 `Run`을 `condition_id`로 두고 Recipe·Si2H6·Power·Temp·Time을 한 행으로 구성했습니다.
3. N2O 4,000 sccm, N2 3,000 sccm, Pressure 2,250 mTorr는 해당 표에서 고정 조건입니다. 빈 NH3 칸을 임의로 0으로 바꾸지 않았습니다.
4. 비교 변수 이외의 조건을 고정한 그룹을 만들어 Gas·Power·온도·시간 변화에 따른 차이를 확인했습니다.

총 25행은 서로 다른 25개 Recipe라는 뜻이 아니라 **25개 공정 실행 기록**입니다. `FT0524_Pre`는 두 번 나타납니다.

## Sensor 전처리와 두 종류의 참고 범위

센서 표를 `process_time, run, si2h6_flow, target` 형태로 바꾸고 시간·센서값이 없는 행을 제외했습니다. Run별 기록 길이가 달라 끝부분의 빈칸은 해당 Run의 관측 종료로 처리했습니다.

공개 Python 분석은 처음 3개 관측을 분리하고 4초 이후를 동일 기준으로 비교합니다.

| 지표 | Run1 | Run2 | Run3 |
|---|---:|---:|---:|
| 평균 유량 (sccm) | 200.0693 | 200.0496 | 200.0111 |
| 표본 표준편차 (sccm) | 0.1488 | 0.1194 | 0.1025 |

![전체 시간축](../images/sensor_stability_by_run.png)

### 원본 Excel의 그래프 범위

- 1% 범위: 200×(1±0.01) = **198–202 sccm**
- 표준편차 범위: `STDEV(B5:D33,C4)` = 약 0.21254 sccm
- 두 번째 선: 200±3×0.21254 = **199.3624–200.6376 sccm**

해당 STDEV 범위에는 Run1·3의 3초 이후와 Run2의 2초 이후 값이 포함됩니다. 따라서 원본 그래프는 **200을 중심으로 통합 표준편차를 적용한 범위**이며, 노트북의 **각 Run 평균을 중심으로 계산한 ±3σ**와 동일하지 않습니다. 이를 원본 수식 그대로 기록했습니다.

안정 구간 평균이 Target에 근접한다는 관찰로 정리했습니다. 이 참고 범위만으로 설비 정상 여부나 양산 관리한계의 유효성을 확정하지 않았습니다.

## 계측 Output 확인

1. `ITEM_ID`로 두께와 GOF를 구분했습니다.
2. 위치 1–49를 세로 형태로 변환해 `condition_id, wf, point, thickness, gof`로 정리했습니다.
3. 결측값을 보존하고, 평균·표준편차 계산에서는 유효한 두께값만 사용했습니다.
4. GOF와 결측 위치를 대조했습니다. 원본에서 확인하지 못한 일괄 제외 임계값은 새로 가정하지 않았습니다.

| Recipe | 조건 번호 | WF | 두께 결측 위치 | 확인 사항 |
|---|---:|---:|---|---|
| Run21 | 23 | 8 | 45, 46, 47, 48, 49 | 같은 위치 GOF 0.81233–0.833123 |
| Run23 | 25 | 10 | 37, 40, 43, 47 | 두께 결측, 원인 미확인 |

현재 파일은 일부 처리가 진행된 상태입니다. 낮은 GOF와 결측의 대응은 확인되지만, 과거 삭제 시점이나 정확한 임계값까지 복원할 수는 없습니다. 결측을 보간하거나 0으로 채우지 않았습니다.

## 연결 키 검증

**공정 파라미터 Run ↔ 계측 데이터 조건 번호**로 연결합니다. Recipe 이름의 `run23`은 조건 번호 25에 해당합니다.

- `WF`는 1–15 이후 다시 1–10으로 반복되므로 단독 연결 키로 사용할 수 없습니다.
- `Recipe`도 Pre가 반복되므로 단독 키로 사용하지 않습니다.
- 계측 데이터에서 `(condition_id, point, ITEM_ID)` 중복을 검사합니다.
- 두께와 GOF는 `(condition_id, point)`로 1:1 연결합니다.
- Input은 `condition_id`로 다대일 연결하고 미연결 행이 있으면 중단합니다.
- 좌표는 `point`로 연결합니다.

구현: [`load_measurements`](../src/detailed_analysis.py). 원본 전체 계측값은 공개하지 않았으며, 원본을 가진 사용자는 해당 함수로 연결과 재계산을 확인할 수 있습니다.
