# 5. 향후 분석 자동화 계획

[전체 분석으로 돌아가기](../README.md)

데이터 정리와 그래프 작성은 직접 수행했고 AI는 해석 보조로 활용했습니다. 이번 저장소에서는 계산·시각화 과정을 코드로 정리했습니다. 아래의 운영 파이프라인과 AI 연동·예측 모델은 향후 계획입니다.

| 단계 | 구현할 기능 | 검증 방법 |
|---|---|---|
| 1. 입력 표준화 | 센서·Recipe·계측 파일의 열 이름, 단위, 조건 식별자 통일 | 중복·누락·미연결 항목과 유효 측정 개수 표시 |
| 2. 반복 분석 자동화 | 검토한 안정 구간 기준, AVG·STD·Range·Uniformity와 map 생성 | 검토된 Excel 사례와 계산 일치, 결측이 0으로 바뀌지 않는지 확인 |
| 3. AI 해석 보조 | 계산된 표·Run 식별자·비교 조건을 전달해 관찰과 추가 질문 초안 생성 | 모든 수치가 계산표에 존재하는지 확인, 관찰과 추정 구분 |
| 4. 사람의 검토 | 원본·그래프·해석 초안을 함께 검토하고 보고서 확정 | Spec 혼동, 수치 오류, 인과 단정, 미측정 성과 표현 점검 |
| 5. 데이터 축적 후 예측 | Recipe와 센서 요약으로 AVG·산포 예측 모델 검토 | 시간 순서로 후속 Run을 분리해 검증, 단순 평균·선형 모델과 오차 비교 |

우선 반복 계산의 재현성과 보고서 검토 시간을 개선 대상으로 삼습니다. 언어 모델에게 계산 자체를 맡기기보다 검증된 표를 해석 입력으로 제공합니다.

예측 모델은 wafer의 49개 위치를 임의로 학습·평가에 섞으면 같은 wafer 정보가 양쪽에 들어갈 수 있으므로 **Run 단위**로 분리합니다. 현재의 25개 실행 기록만으로 범용 공정 예측 성능을 주장하지 않습니다.
